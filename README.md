# 시혐지

시험지 + 혐오. 시험 후 스트레스를 푸는 PC 브라우저용 2D 게임입니다.

## 실행

Node.js 22.12 이상 환경에서 `npm install` 후 `npm run dev`를 실행합니다.
`npm run build`는 배포용 dist 폴더를 생성합니다. `npm test`는 입력 규칙을 확인합니다.

## 플레이

1. 과목을 1~8개 추가하고 **책상에 앉기**를 누릅니다.
2. 시험지와 처리 방식을 선택합니다.
3. 구기기는 화면을 6번, 파쇄기는 8번 클릭하면 완료됩니다.
4. 책상 엎기를 선택하고 스페이스바를 1.5초 이상 누른 뒤 놓습니다.
5. **책상 다시 세팅하기**로 같은 과목을 다시 플레이합니다.

터치 환경에서는 책상 엎기를 선택하고 게임 화면을 길게 누른 뒤 놓을 수도 있습니다.
과목은 이 브라우저의 로컬 저장소에 저장됩니다. 과목 수정에서 삭제할 수 있습니다.
소리는 브라우저에서 합성하며, 우측 상단에서 끌 수 있습니다.

## 구성

Phaser 3.90 / TypeScript / Vite. 그림은 Canvas로 직접 생성하며 효과음은 Web Audio로 합성합니다.
충전은 기준 시간에 도달해도 자동 발동하지 않습니다. 손을 떼는 순간 발동하며,
짧게 누르기, 창 포커스 이탈, 탭 전환, 모드 변경, 초기화는 충전을 취소합니다.
