# 시혐지 3D 구조

## 실행 흐름

`main.ts`가 `GameController`를 만듭니다. 컨트롤러가 저장된 과목과 설정을 읽고, HTML 화면과 3D 공간을 초기화합니다.

사용자 입력 → `GameStore`의 상태 변경 → `GameController`가 HTML과 3D에 변경 전달 → 각 화면 모듈이 표시와 애니메이션 갱신

## 각 계층의 책임

### domain — 게임 규칙

`GameStore`가 과목, 선택한 시험지, 처리 방식, 진행 횟수, 완료 여부를 관리합니다. 브라우저 화면이나 3D 엔진을 불러오지 않습니다. `snapshot`은 복사본이라 외부에서 수정해도 원본 상태가 바뀌지 않습니다.

`rules.mjs`에는 구기기 6회, 파쇄기 8회, 충전 1500ms 등 숫자와 순수 함수를 둡니다. Node에서 바로 테스트할 수 있도록 이 작은 파일은 JavaScript 모듈을 사용합니다.

### input — 입력

`InteractionController`는 게임 영역의 클릭과 스페이스바만 담당합니다. 화면 버튼은 `GameUI`가 처리하므로 과목 선택이나 도구 선택이 처리 클릭으로 집계되지 않습니다.
충전 시간은 단조 증가 시간인 `performance.now()`로 측정합니다. 시간 도달은 준비 상태이며, 발동은 손을 뗄 때만 일어납니다. 짧게 누르기, 창 포커스 이탈, 탭 숨김, 모드 변경, 초기화는 충전을 취소합니다.

### ui — HTML 화면

`template.ts`는 화면 뼈대, `icons.ts`는 아이콘, `GameUI.ts`는 상태 표시와 버튼 연결, `style.css`는 스타일을 담당합니다. 과목 이름은 `textContent`로 넣고 HTML로 해석하지 않습니다.

### three — 3D 표시

`World3D`가 렌더러, 물체 배치, 프레임 루프를 관리합니다. 카메라는 `CameraRig`가 담당합니다. `Room`, `Desk`, `PaperModel`, `Shredder`가 각자의 모양을 만듭니다.

- 종이 구기기: 작은 삼각형으로 나눈 종이의 정점을 단계적으로 변형합니다.
- 파쇄기: 남은 종이 길이와 인쇄 영역을 함께 줄이고, 물리 조각을 생성합니다.
- 책상 엎기: 첫 0.9초는 회전 방향을 제어하고, 이후 책상을 물리 물체로 전환합니다. 소품은 시작할 때 분리되어 중력과 충돌을 받습니다.
- 화면 크기 변경은 `ResizeObserver`가 감지합니다. 렌더러 픽셀 비율과 파쇄 조각 수는 제한합니다.

### physics — 물리

`PhysicsSystem`만 Rapier 물리 월드와 바디를 생성·이동·제거합니다. 물리는 1/60초 고정 간격으로 계산합니다. 다시 하기는 기존 물리 바디와 파쇄 조각을 제거한 뒤 새 책상을 구성합니다.

### services — 저장과 소리

`storage.ts`는 브라우저 저장소 오류를 처리합니다. 저장이 막혀도 플레이할 수 있습니다. `audio.ts`는 사용자 조작 후 효과음을 합성합니다.

## 기능 추가 예시

새 처리 방식을 추가할 때는 `domain/types.ts`의 모드, `GameStore`의 처리 규칙, `GameController`의 연결, 해당 3D 물체와 UI 버튼을 순서대로 추가합니다. UI에서 직접 물리 바디를 조작하지 않습니다.

카메라 위치나 종이 크기는 `config.ts`, 횟수와 충전 시간은 `domain/rules.mjs`에서 조정합니다. 독립적으로 수정한 뒤 `npm test`와 `npm run build`로 확인할 수 있습니다.

## 사용자 시점과 통합 입력

`CameraRig`는 OrbitControls를 사용합니다. 왼쪽·오른쪽 드래그는 회전, 휠은 확대·축소, 가운데 버튼 드래그는 평면 이동으로 연결합니다. 터치에서는 한 손가락으로 회전하고 두 손가락으로 확대·축소 및 이동합니다. 입력을 멈추는 별도 모드는 없습니다.

`PointerGestures`는 게임 입력과 카메라가 공유하는 판별 규칙입니다. 화면상의 8픽셀 이상 움직이면 해당 누르기를 드래그로 기록하며, 다시 시작점으로 돌아와도 클릭으로 처리하지 않습니다. 여러 손가락이 관여한 경우 마지막 손가락을 뗄 때까지 탭 처리를 막습니다.

`InteractionController`는 누르는 순간 게임을 실행하지 않고, 손을 뗄 때 드래그나 여러 손가락 조작이 아니었는지 확인한 후 한 번만 처리합니다. 책상 엎기에서 포인터로 충전하다 드래그하면 그 충전을 취소합니다. 스페이스바 충전은 카메라 조작과 함께 사용할 수 있습니다.

카메라의 자동 시점 변경은 실제 드래그·휠 조작을 시작한 후 멈추므로 단순 클릭은 자동 시점을 끄지 않습니다. ‘원위치’나 ‘전체 보기’를 누르면 관성을 비우고 해당 시점으로 부드럽게 복귀합니다. 이동 거리·각도·민감도는 `config.ts`의 `camera.controls`에서 조절합니다.
