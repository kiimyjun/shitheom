# 시혐지 3D 구조

## 실행 흐름

`main.ts` → `GameController` → `GameStore` 상태 변경 → HTML 화면과 3D 표시 갱신.
과목을 추가하면 즉시 플레이 상태가 됩니다. 별도의 시작 화면이나 도구 선택 상태가 없습니다. 과목 편집과 초기화는 진행 중인 입력과 자동 파쇄를 취소하고 책상을 다시 구성합니다.

## 모듈별 책임

| 모듈 | 책임 |
| --- | --- |
| `domain/GameStore.ts` | 과목, 시험지 선택, 구기기 완료, 파쇄 단계, 책상 엎기와 초기화. DOM·시간·3D에 의존하지 않음 |
| `domain/rules.mjs` | 과목 정규화, 최대 8과목, 1500ms 충전, 종이 처리 단계 |
| `game/GameController.ts` | 모듈 연결, 자동 파쇄 타이머, 효과음, 저장. 초기화·엎기·종료 때 타이머 취소 |
| `input/InteractionController.ts` | 시험지 클릭·더블클릭·드래그, 스페이스바 누르기와 놓기, 입력 취소 |
| `input/PointerGestures.mjs` | 8픽셀부터 드래그 판정. 시작점으로 돌아와도 드래그 유지. 여러 손가락은 탭 방지 |
| `input/PaperTaps.mjs` | 같은 시험지를 가까운 위치에서 연속 두 번 탭했는지 판정 |
| `ui/template.ts`, `ui/GameUI.ts` | 접이식 과목 패널, 초기화, 소리·카메라 버튼, 처리 상태·충전·드래그 안내 |
| `style.css` | 창 전체 3D 화면 위 HUD 배치와 작은 화면 대응 |

| `services/storage.ts`, `audio.ts` | 브라우저 저장과 Web Audio 효과음 |

## 직접 조작

포인터를 누를 때 종이인지 빈 공간인지 결정합니다. 종이에서 시작한 드래그는 종이를 옮기고, 빈 공간에서 시작한 드래그는 카메라를 회전합니다. 이동 중 다른 물체를 지나도 소유권이 바뀌지 않습니다. 모드 전환은 없습니다.

단순 클릭은 선택만 합니다. 드래그가 아닌 두 클릭이 같은 종이에 들어오면 `crumple(id)`가 완료 상태를 만들고 3D가 부드럽게 구겨집니다. 종이를 파쇄기 영역에 놓으면 `beginShred(id)`로 잠그고 자동으로 `shredStep(id)`를 진행합니다. 한 번에 한 장만 투입할 수 있고, 다른 종이는 그동안 구길 수 있습니다.

처리 이벤트에는 변경된 `paperId`가 들어갑니다. 자동 파쇄 중 다른 시험지를 선택해도 올바른 종이만 갱신됩니다. 스냅샷은 복사본이며, 구긴 종이·파쇄 중인 종이·책상을 엎은 뒤에는 같은 종이를 다시 처리할 수 없습니다.

스페이스바 충전은 도구와 무관합니다. `performance.now()`로 측정하고, 1.5초에 도달해도 손을 뗄 때만 뒤집힙니다. 입력창·버튼에서의 키 입력, 창 포커스 이탈, 숨겨진 탭, 초기화는 오작동을 방지합니다. 설정 패널을 접거나 화면 버튼을 누른 뒤에는 게임 영역에 포커스를 돌려줍니다.

## 표시와 확장

종이의 모양은 정점 변형으로 만들고, 파쇄는 종이 길이와 인쇄 영역을 줄이며 물리 조각을 방출합니다. 구겨진 종이는 공 형태의 물리 바디로 전환합니다. 책상 엎기는 첫 0.9초 회전을 제어한 뒤 물리 바디로 전환하며 소품은 시작 순간 분리됩니다.

`ResizeObserver`가 화면 크기를 반영합니다. 좁고 긴 화면에서는 시야각을 넓혀 책상과 파쇄기를 모두 보여 줍니다. 카메라 위치·감도·이동 범위는 `config.ts`, 더블클릭 판정은 `PaperTaps.mjs`, 자동 파쇄 속도는 `GameController.ts`의 상수에서 조정합니다.

새 동작은 상태 규칙, 컨트롤러 연결, 해당 물체의 표시를 각각 추가합니다. HTML 화면에서 직접 물리 바디를 조작하지 않습니다. 과목 이름은 `textContent`와 Canvas로 표시하여 HTML로 해석하지 않습니다.

`npm test`는 입력 판정과 직접 동작·동시 파쇄 제한·초기화 규칙을 검사합니다. `npm run build`는 타입 검사와 배포 파일 생성을 수행합니다.
